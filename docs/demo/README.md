# Memory Fabric demo

[Watch the demo](memory-fabric-demo.mp4)

This is a real Mac app screen recording, cropped to its window. A demo fact was
sent from the physical iPhone: Project Aurora's launch code is cobalt mango 47.
The user tapped Sync on the phone. The Mac retrieved the imported MiniLM vectors
through the learned MiniLM → MPNet adapter and answered with its local LFM3 model.

This take demonstrates real cross-device sync and translated-memory retrieval.
It does not establish that the installed phone build synced automatically.
No cloud generation call was made for this demonstration.
